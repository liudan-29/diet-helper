# 饮食小助手

## 这是干嘛的

一个网页版饮食决策工具：用户选择餐次、场景和预算后，获得附近合适餐厅的推荐与导航入口。第一版先用模拟数据跑通“去哪吃”，再接入高德 MCP 获取真实数据。

## 怎么跑

需要Node.js 20或更高版本。首次运行安装依赖：

```powershell
npm install
npm start
```

访问 `http://localhost:4173`。

复制 `.env.example` 为 `.env`，填入高德开放平台中“Web服务”类型的Key：

```text
AMAP_MCP_KEY=你的Key
```

没有配置Key时，项目自动使用演示餐厅数据；配置后，服务端通过高德MCP周边搜索查询真实餐厅。

## 备注

- 当前已包含Node服务端、用餐条件校验、餐厅筛选排序与高德MCP客户端。
- 高德和模型服务密钥仅配置在本地 `.env` 文件或部署平台环境变量中，不能提交到仓库。
- 第一版不做原生 APP、微信小程序、支付、社交和医疗建议。
- MVP 暂时只展示“去哪吃”，不代表其他功能被取消。完整功能与暂缓原因见 `docs/product-roadmap.md`。
