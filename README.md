# 饮食小助手

## 这是干嘛的

一个网页版饮食决策工具：用户选择餐次、场景和预算后，获得附近合适餐厅的推荐与导航入口。第一版先用模拟数据跑通“去哪吃”，再接入高德 MCP 获取真实数据。

## 怎么跑

这是无构建步骤的静态网页。用任意静态服务器打开项目目录即可，例如：

```powershell
npx serve .
```

访问命令输出的本地地址。

## 备注

- 当前页面是可交互原型，餐厅数据为模拟数据。
- 高德和模型服务密钥仅配置在本地 `.env` 文件或部署平台环境变量中，不能提交到仓库。
- 第一版不做原生 APP、微信小程序、支付、社交和医疗建议。
- MVP 暂时只展示“去哪吃”，不代表其他功能被取消。完整功能与暂缓原因见 `docs/product-roadmap.md`。
